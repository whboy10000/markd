## 1. 十分钟上手

**安装**：从 [Releases](https://github.com/whboy10000/markd/releases/latest) 下载对应平台的安装包。

- macOS：`Markd-*-macos-universal.dmg`（通用）或按芯片选 intel / apple-silicon；打开后把 Markd 拖进「应用程序」。首次运行若提示「无法验证开发者」，执行 `xattr -d com.apple.quarantine /Applications/Markd.app`。
- Windows：`Markd-*-windows-setup.exe`，安装向导中可勾选创建桌面与开始菜单快捷方式。
- Linux：`Markd-*-linux-amd64.deb`（`sudo dpkg -i`）或 `.rpm`（`sudo rpm -i`），两者都会注册应用菜单项；也可以解压 `.tar.gz` 直接跑二进制。

**第一次打开**（全新配置，未写过 `~/.markd/config.json`）会直接给你一个空白文档，并且默认收起侧栏、大纲与格式工具条——界面只有编辑区，先写起来。之后再次启动时：

1. `Cmd/Ctrl + O` 浏览文件，或 `Cmd/Ctrl + Shift + O` 在当前工作区里按名字快速找文件；
2. 直接把 `.md` 文件从 Finder / 资源管理器**拖到窗口**里也能打开；
3. 开始输入：默认所有文本都是段落，用 `Cmd/Ctrl + 1…6` 变成各级标题，`Cmd/Ctrl + 0` 变回段落；
4. `Cmd/Ctrl + S` 保存。文档还没落盘过时会弹出「另存为」让你选位置，之后每次 `Cmd/Ctrl + S` 直接写回原文件；
5. 想临时看 Markdown 源码，按 `Cmd/Ctrl + /`（或 `Cmd/Ctrl + E`）切到源码模式，再按一次切回。

关掉首个文档后，之后的启动会按「启动时恢复上次打开的文件」设置恢复现场；没有可恢复文件时显示首页（欢迎页 + 最近打开列表）。

## 3. 核心概念：Hybrid View

**当前正在编辑的块显示 Markdown 源码，其余块实时渲染成富文本。**

- 鼠标点进一个段落，它就变成源码编辑框，你能精确看到并修改 `**`、缩进、空行、标记顺序；
- 焦点离开（点到别处、按方向键移出），它立刻回到渲染态；
- 因此源文件里的细节不会被自动格式化「吃掉」——Markd 不做「解析成 AST 再重新打印」，写回磁盘的就是你输入的字节。

块 = 一个标题 / 段落 / 引用 / 列表项 / 表格 / 代码块 / 公式 / Mermaid / 图片 / 分隔线 / 空行。这个概念决定了几个日常行为：

- 光标行高亮、行号都是**按块**给出的；
- 「插入表格 / 公式 / 代码块」等命令作用于**当前块所在处**；
- 代码块、表格、公式这类复杂块在渲染态下是「只读展示」，要改内容必须点进去（或用源码模式）。

## 4. 文本编辑基础

| 操作 | 行为 |
|---|---|
| `Enter` | 在当前块内换行；位于块尾时新建下一块（编辑态由块的类型决定标题 / 代码块等特殊行为） |
| `Backspace` 于行首 | 与前一块合并。**例外**：代码块 / 图表 / 代码组这类带 ` ``` ` 围栏的块不动光标、不并块（否则一个退格就把整块代码打回普通文字）；要退出这种块，在空块里连按两次 `Enter`，或点块头「删除」 |
| `↑` / `↓` | 跨块移动光标，到块边界自动切到相邻块 |
| `Tab` / `Shift + Tab` | 列表项内：增加 / 减少一级缩进（步长 = 偏好设置里的 Tab 宽度）；非列表块内：插入缩进 |
| 鼠标拖选 | 支持从标题拖进段落、跨越代码块 / 图片 / 公式的**跨块选区**；拖拽期间活动块保持编辑态，避免布局跳动 |
| `Cmd/Ctrl` + 单击链接 | 打开链接；不带修饰键单击不会误触发（编辑态内尤其重要） |
| 右键 | 上下文菜单：剪切 / 拷贝 / 粘贴，以及「段落 / 格式 / 插入」子菜单；「复制为 / 粘贴为」支持 Markdown、纯文本、HTML 三种目标 |
| `Cmd/Ctrl + C` / `X` | 复制 / 剪切，剪贴板同时写入**带格式 HTML**，粘贴进 Word / 浏览器保留样式 |
| `Cmd/Ctrl + V`（剪贴板里是图片） | 自动把截图落盘到资源目录并插入图片链接 |
| `Cmd/Ctrl + Z` / `Shift + Z` | 撤销 / 重做。记录按块存差量，连续输入按 450 ms 合并成一组，上限 200 组 |
| 拖拽文件到编辑区 | `.md` → 打开该文档；图片 → 插入图片链接；PDF / Word / Excel 等附件 → 插入附件卡片（[§6.10](#610-文件附件)）；其它扩展名不响应 |

删除代码块与表格会弹确认窗（这两类块内容多，误删代价大）。

## 5. Markdown 语法支持

**块级**

| 写法 | 说明 |
|---|---|
| `#` … `######` | ATX 标题（1–6 级）；`文本` 下加 `===` / `---` 为 Setext 一 / 二级标题 |
| 空行分隔 | 段落切分 |
| `>`、`> >` | 引用，支持嵌套块；点进去编辑时左侧竖线与文字起点都不移动 |
| `- item` / `* item` / `1. item` | 无序 / 有序列表，两空格缩进表示嵌套 |
| `- [ ]` / `- [x]` | 任务列表，渲染态可直接点选勾选 |
| `---` / `***` | 分隔线 |
| ` ```lang ` … ` ``` ` | 围栏代码块，`lang` 决定高亮语言与代码组标签 |
| `\| 列 \| 列 \|` + `---` 行 | 表格，`---:` / `:---:` / `:---:` 控制右 / 左 / 对齐 |
| `[^1]` 与 `[^1]: 内容` | 脚注引用与定义，自动编号 |
| 文件顶部 `---` … `---` | YAML Front Matter，以代码面板呈现（无功能栏，悬停才浮现操作按钮），不混入正文 |
| `[TOC]` | 就地插入目录（可在偏好设置里整体关掉） |
| ` ```video ` + 一行 B 站链接 | 哔哩哔哩视频卡片，导出 HTML 时变成可播放的 `<iframe>`（[§6.9](#69-视频哔哩哔哩)） |
| 独占一段的 `[名](x.pdf)` | 附件卡片（PDF / Word / Excel / 压缩包…），点开即本机直开或后台下载后预览（[§6.10](#610-文件附件)） |

**行内**

`**粗体**`、`*斜体*`、`__下划线__`、`~~删除线~~`、`==高亮==`、`` `行内代码` ``、`上标/下标`、`[文字](url)`、`![alt](src)`、`<http://自动链接>`、`$行内公式$`、`[[双向链接]]`、`\` 硬换行。行内标记可以嵌套混用（如 `**加粗里带==高亮==**`）。

导出 HTML 与「复制为 HTML」使用同一套渲染结果，所见即所得。

## 6. 内容块详解

### 6.1 标题与目录

`Cmd/Ctrl + 1…6` 设级别，`Cmd/Ctrl + 0` 变回段落。偏好设置 → Markdown → **标题自动编号**打开后，预览里各级标题按 `1.` / `1.2` / `1.2.3` 显示编号（只影响显示，不写进文件）。`[TOC]` 块渲染成可点击目录，点击跳转到对应标题。

### 6.2 列表与任务

无序 / 有序 / 任务列表在渲染态可以直接点勾选框。缩进层级会体现在导出的 HTML 与嵌套渲染上。改变层级用 `Tab` / `Shift + Tab`，或插入两个空格。

### 6.3 表格

`Cmd/Ctrl + Option + T`（macOS）/ `Ctrl + Alt + T` 或菜单「段落 → 插入表格」弹出对话框，输入行列数（默认 3×3）。对话框在**正文区正中**弹出，不再停在左上角。插入后点表格进入源码态编辑单元格文本；对齐符号写在分隔行里（`|:---|---:|`）。表格宽度自适应正文区宽度，超宽时横向滚动。

需要输入或确认的模态对话框一律居中且不可拖动：插入表格、插入链接、插入视频、插入文件、新建文件/新建文件夹、重命名、删除确认、打开工作区，另外「有未保存的修改」也是同款。「关于 Markd」「快捷键一览」是参考面板（后者内容比窗口还高），保持可拖动、不居中。

### 6.4 代码块与代码组

插入：`Cmd + Option + C`（macOS）/ `Ctrl + Alt + C`，菜单「段落 → 插入代码块」，或工具条**「代码」下拉**里的「代码块」（该下拉三项依次是「行内代码 / 代码块 / 代码组」，和 [§6.5](#65-数学公式) 的「公式」下拉同款收法）。渲染态头部一条功能栏：

- 左侧是**语言标签下拉**，换语言立刻改变高亮；
- 右侧依次是**复制**、**删除**（弹确认）、**折叠 / 展开**。折叠状态按代码块的**源码文本**记录，写入 `~/.markd/folds.json`，重启后保持（内容相同的两块会共享折叠状态）。

代码区支持行号与当前行高亮（受「显示行号栏」开关控制）。语言下拉有 **460+ 行**：规范名和它的每个别名**各占一行**，覆盖主流语言、脚本与命令行、配置与 IaC、数据库方言、着色器与硬件、函数式与学术语言、排版与图表 DSL。所以 `cpp` 与 `c++`/`cxx`/`cc` 都能在列表里点到，`dart` 与 `flutter` 都在，`yaml` 与 `yml`/`k8s`/`helm`/`github-actions`/`docker-compose` 都在，`go` 与 `golang`、`csharp` 与 `c#`、`bash` 与 `shell`/`shell-session` 同理。**点哪一行就把哪一行原样写进围栏信息行**，别名行悬停会提示「与 `dart` 等价」；两种写法的高亮效果完全一致（解析按小写键，手写 ```` ```CPP ````、```` ```C++ ```` 也认）。输入框实时过滤、大小写不敏感，纯文本始终排在第一行。

语法高亮仍是自研词法着色，分三层决定效果：

- **配色族** 10 个：Rust、Python、JavaScript/TypeScript、C 系（C/C++/Java/Go/Kotlin/Swift/Dart/Rust 之外的 `//` 系语言）、Markup（HTML/XML/模板）、CSS、数据格式（JSON/YAML/TOML/INI）、Shell、SQL、通用回退；
- **注释语法按语言**给出，而不是跟着配色族：`//`、`#`、`--`、`%`、`;`、`!`、`::` / `rem`、`dnl`、`\*`、`%%`，块注释支持 `/* */`、`<!-- -->`、`{- -}`、`(* *)`、`{ }`、`--[[ ]]`、`#= =#`、`(: :)`；正文型语言（Markdown/纯文本/CSV/diff/LaTeX 正文）不启用 `//`，链接里的 `//` 不会被染成注释；
- **关键字表**：通用表按族取用，Dockerfile、Makefile、CMake、Terraform/HCL、Nginx、Lua、Haskell、Ruby、Go、LaTeX、MATLAB、Julia、R、Elixir、Clojure、Solidity、GraphQL 另有一张专属表，避免把别族的关键字误标或漏标。

**YAML Front Matter 用同一个代码面板渲染，但不画功能栏**：文件顶部的 `---` … `---` 块只显示 YAML 高亮区，静止时上方没有任何按钮条——front matter 紧挨着文档开头，常驻功能栏会把「一个字段列表」渲染成「一块要操作的工具面板」，看着吵。鼠标移进这块面板时，折叠 / 删除 / 复制三个按钮浮现在面板右上角（悬停前后代码区的位置完全不变，不会一动鼠标整篇文档就往下跳），点「删除」只弹确认窗、不会顺手把光标锚进 YAML。悬浮条上没有语言标签：改语言对 front matter 没有意义。「复制」取到的是两行 `---` 之间的 YAML 正文；源码里的 `---` 边界、导出 HTML 的 front matter 处理、大纲归类都不受这次外观变化影响。点进编辑态时仍是含 `---` 的原始文本且不逐字高亮：编辑 front matter 必须看得见、也删得掉那两行边界。普通代码块不受影响，功能栏常驻。

**代码组**（菜单「段落 → 插入代码组（多语言 Tab）」，或工具条「代码」下拉的第三项）把同一算法的多语言实现放进一个块，渲染成可切换的 Tab；导出 HTML 时保留 Tab 切换。

代码块末尾回车行为对齐 Typora：在最后一行行尾回车新建一行；在末尾空行上再回车则退出代码块、在其下方插入普通段落。

代码块里的鼠标与退格：

- **点哪个字符，光标就落在哪个字符**（包括第一行第一个字符），不会跳到整段代码末尾；
- 按住拖动只选中**指针经过的那几行**，不会一下子整块选中；拖动途中指针飘到功能栏或面板留白，端点仍跟着指针走；
- **光标在第一行第一个字符按 `Backspace` 什么都不发生**：代码块 / 图表 / 代码组不会被退格并回上一块，正文删到空也只留一个空代码块，围栏不会丢。要把这种块去掉，用块头「删除」或在空块里连按两次 `Enter`。

### 6.5 数学公式

三种写法：行内 `$E=mc^2$`、块级 `$$ ... $$`、代码块 ` ```math `。工具条上它们收在**一个「公式」下拉**里，三项依次是「行内公式 / 公式块 / 代码块公式」（不再各占一个平铺按钮）；原生菜单里同名的三项在「段落」菜单下。

公式由 RaTeX 排成显示列表，再由 Markd 细分成三角形直接交给 GPU 绘制：**不生成 PNG、不走纹理**，所以放大不失真、颜色跟随主题。行内公式按文字基线对齐；块级公式居中、超宽时等比缩小。行内自动用 `\textstyle`、块级用 `\displaystyle`，与 LaTeX 一致。渲染结果按 `(公式, 字号, 显示模式)` 缓存。

不想让 `$` 被当公式解析时，在偏好设置 → Markdown 里关掉「数学公式」。

### 6.6 Mermaid 与流程图

### 6.8 图床（把图片传到远端，文档里写公网 URL）

偏好设置 → 图像 → 图床，平台九个选项：关闭、Gitee 仓库、GitHub 仓库、阿里云 OSS、七牛云 Kodo、火山引擎 TOS、百度智能云 BOS、华为云 OBS、腾讯云 COS。仓库平台填用户名、仓库、分支、令牌；OSS 填地域、存储空间（Bucket）、AccessKey ID、AccessKey Secret；七牛填区域、空间名称、AccessKey、SecretKey、访问域名；火山填地域、存储桶、AccessKey、Secret Access Key；百度填地域、存储桶、AccessKey、Secret Access Key；华为填区域、桶名、访问密钥 ID（Access Key Id）、秘密访问密钥（Secret Access Key）；腾讯填地域、存储桶、SecretId、SecretKey。目录与保存路径模板是所有平台公用的。

- 保存路径模板支持 `{year}` `{month}` `{day}` `{hour}` `{minute}` `{random}` `{filename}` `{suffix}` `{.suffix}`，默认 `{year}/{month}/{day}`；`{random}` 是每次上传换一次的 6 位十六进制，`{filename}` 是清理成 ASCII 的原名主干，`{.suffix}` 带点、`{suffix}` 不带点。
- 模板里写了 `{filename}` 就等于由模板决定文件名，不再自动加毫秒时间戳前缀；没写就沿用「毫秒时间戳-原名」。
- **GitHub**：走仓库 Contents API（一次上传 = 一次提交），令牌要 **Contents: Read and write**（Fine-grained token 的 Repository permissions → Contents），链接是 `https://raw.githubusercontent.com/<用户名>/<仓库>/<分支>/<路径>`。同路径重复写会先读旧文件 SHA 再覆盖（不这么做实测回 `422 "sha" wasn't supplied`）。
- **Gitee**：走 OpenAPI v5，令牌需要 projects 权限。
- **阿里云 OSS**：`PUT https://<桶>.<地域>.aliyuncs.com/<对象名>`，用 V1 签名（`base64(HMAC-SHA1(AccessKeySecret, 待签字符串))`，待签字符串里带 `Date` 与 `Content-Type`）。地域写 `oss-cn-shanghai`，也接受 `cn-shanghai`、完整 endpoint、桶的三级域名和控制台中文名「华东2（上海）」，设置页会归一处理。链接是 `https://<桶>.<地域>.aliyuncs.com/<对象名>`。**桶必须是公共读**：私有桶写进去的链接公网打不开（编辑器预览也读不到）。签名依赖本机时间，与标准时间差 15 分钟以上会 403。
- **七牛云 Kodo**：走「表单上传」——`POST https://up-<区域>.qiniup.com/`，`multipart/form-data` 里带 `key`、`token` 与文件本体；`token` 是上传凭证 `AccessKey:urlsafe_base64(HMAC-SHA1(SecretKey, urlsafe_base64(上传策略))):urlsafe_base64(上传策略)`，上传策略就是 `{"scope":"<空间名>:<对象名>","deadline":<秒>}`，每次上传现签、1 小时有效。区域写 `z2`，也接受控制台中文名「华南-广东」、只写「华南」「广东」，以及 `up-z2.qiniup.com` / `rs-z2.qiniuapi.com` 这种整串域名，设置页会归一；填了不认的区域会在「测试上传」时直接把八个可选项列出来。同名对象直接覆盖，不需要像 GitHub 那样先取 SHA。**访问域名必填**（七牛不能从空间名推出域名）：填了自定义域名按 `https://<域名>/<对象名>` 写链接，填的是 `*.clouddn.com` 这类七牛测试域名则按 `http://` 写——实测测试域名没有匹配该主名的 HTTPS 证书（https 回 421、http 回 200）。测试域名只作联调用（有效期与限速都有约束），长期用建议绑自己的域名。签名与凭证都依赖本机时间，时钟不准会一直 401。
- **百度智能云 BOS**：走 `PUT https://<桶>.<地域>.bcebos.com/<对象名>` + `bce-auth-v1` 签名。签名是两段的：先用 SecretKey 对信任状 `bce-auth-v1/<AccessKey>/<UTC 时间>/1800` 做 HMAC-SHA256 取十六进制，**再把这段十六进制字符串本身当密钥**去签规范请求（`方法\n规范化 URI\n规范化查询串\n规范化头`）。规范化头里名与值都要百分号编码——实测 `image/png` 进签名是 `image%2Fpng`、时间里的 `:` 是 `%3A`，只编码名字不编码值是签不上的；空值的头不参与，各行按字节排序。发出去的 `Authorization` 末尾形如 `/1800//<签名>`，中间那段「参与签名的头名」留空表示按服务端默认集合（`host`、`content-md5`、`content-length`、`content-type` 加所有 `x-bce-*`）算，与官方 SDK 一致。请求必须带 `x-bce-date`：实测不带它服务端直接回 `400 MissingDateHeader`。地域写 `bj`，也接受控制台全称「华北-北京」、只写「北京」，以及 `bj.bcebos.com`、`https://bj.bcebos.com` 和桶的三级域名 `markd-markd.bj.bcebos.com`，设置页会归一；官方开放的八个地域是 bj/bd/su/gz/cd/hkg/fwh/fsh，写成认不出的文字会在「测试上传」时把这份列表列给你，写成没列过但形如两三个小写字母的 ID 则放行。链接就是桶域名拼对象名，不需要额外填域名；要挂自己的 CDN 就填 `image_host_public_base`。信任状里带 UTC 时间与 1800 秒有效期，本机时钟不准会一直 403（`SignatureDoesNotMatch`）；桶是私有读时文档里的链接公网打不开，需要设成公共读或自己配 CDN。
- **火山引擎 TOS**：走 `PUT https://<桶>.tos-<地域>.volces.com/<对象名>` + V4 签名（`Authorization: TOS4-HMAC-SHA256 Credential=<AK>/<日期>/<地域>/tos/request, SignedHeaders=…, Signature=<hex>`，签名密钥是 `SecretKey → 日期 → 地域 → tos → request` 的四轮 HMAC-SHA256，请求体摘要 `x-tos-content-sha256` 也进签名链）。地域写 `cn-beijing`，也接受控制台中文名「华北2（北京）」、只写「北京」，以及 `tos-cn-beijing.volces.com`、`tos-s3-cn-beijing.volces.com` 和桶的三级域名，设置页会归一；填了没见过的 `xx-yyyy` 直接放行，写成别的文字则报错并列出可用地域。链接就是桶域名拼对象名，不需要额外填域名；要挂自己的 CDN 就填 `image_host_public_base`。原生端点只认 TOS4 签名（实测给它 AWS SigV4 会回 `InvalidArgument: Unsupported Authorization Type`），火山另有 S3 兼容域名 `tos-s3-<地域>.volces.com`，Markd 不走那条。签名带 UTC 时间戳，本机时钟不准会 403；桶是私有读时文档里的链接公网打不开，需要设成公共读或自己配 CDN。
- **华为云 OBS**：走 `PUT https://<桶>.obs.<区域>.myhuaweicloud.com/<对象名>` + V2 签名（`Authorization: OBS <访问密钥 ID>:<base64(HMAC-SHA1(秘密访问密钥, 待签字符串))>`）。待签字符串五段`PUT\n<空 Content-MD5>\n<Content-Type>\n<Date>\n/<桶>/<对象名>`，与阿里云 OSS 的 V1 同一条式子（代码里共用一个函数），差别只有一处：**对象名必须先百分号编码再进签名**，斜杠保留、空格与 `#` 与中文都编码（实测对象名写成 `探针 A#1 目录/Shot.png`，编码后 200、公网读回字节一致；把原始对象名直接签进去，华为回 `403 SignatureDoesNotMatch`）。`Date` 用 RFC1123 GMT 且不受系统 locale 影响，华为文档写明与服务器时间差过 15 分钟就回 403。区域写 `cn-east-3`，也接受控制台全称「华东-上海一」，以及 `obs.cn-east-3.myhuaweicloud.com` 和桶的三级域名 `markd-makrd.obs.cn-east-3.myhuaweicloud.com`，设置页会归一；八个有中文全称的区域是「华北-北京一/二/四、华北-乌兰察布一、华东-上海一/二、华南-广州、西南-贵阳一」，其它区域请直接写区域编码；写成认不出的文字会报错并列出这份名单（只写「上海」「北京」这种半截名不猜，按原样交出去）。实测桶名对、区域错时华为回的是 `404 NoSuchBucket`，不是签名错。错误正文是 XML（`<Code>`/`<Message>`），跟阿里云 OSS 一样按 Code 翻成中文并把华为原话带出来。链接就是桶域名拼对象名；桶是公共读时文档里的链接才打得开，要挂自己的 CDN 就填 `image_host_public_base`。
- **腾讯云 COS**：走 `PUT https://<桶>.cos.<地域>.myqcloud.com/<对象名>` + v5 签名（`Authorization: q-sign-algorithm=sha1&q-ak=<SecretId>&q-sign-time=<起>;<止>&q-key-time=<同>&q-header-list=<头名排序>&q-url-param-list=&q-signature=<hex>`）。签名是**两段**的：先用 SecretKey 对 `q-sign-time` 那串做 HMAC-SHA1 取十六进制，**再把这段十六进制字符串本身当密钥**去签待签字符串 `sha1\n{时间窗}\n{格式串的 SHA1}\n`；格式串是 `put\n/{对象名}\n\n{签名头}\n`（第三行是 URL 参数，对象写入恒为空）。**这里与华为 OBS 正好相反：对象名要按原样进签名，不能百分号编码**（实测对象名 `探针 A#1 目录 %x+y/Shot.png` 原样签 200、逐字节读回一致；先编码反而回 `403 SignatureDoesNotMatch`）；反过来**头的值要编码**（`image/png` 签进去是 `image%2Fpng`），且 `q-header-list` 必须与真正签进去的头一一对应——实测声明了没签、或签了没声明都回 `SignatureDoesNotMatch`。时间窗是 `{现在-60};{现在+10000}`，超了回 `403 AccessDenied`（原话 `Request has expired`）。**桶名必须写成「名称-APPID」**（如 `markd-1253518225`）：实测不带后缀回 `400 InvalidRequest`，原话直接给了 `Bucket format should be <bucketname>-<appid>`。地域写 `ap-nanjing`，也接受控制台全称「南京」「公有云园区-中国-南京」，以及 `cos.ap-nanjing.myqcloud.com` 和桶的三级域名 `markd-1253518225.cos.ap-nanjing.myqcloud.com`，设置页会归一；官方 22 个地域都带中文对照（境内 7 + 金融云 3 + 港澳亚太 7 + 中东/欧美 5），写成认不出的文字会报错并列出这份表，写成没在表里但形如 `ap-xxx` 的新地域放行；粘全球加速域名 `cos.accelerate.myqcloud.com` 会单独提示 Markd 不走那条。实测桶名对、地域错回的是 `404 NoSuchBucket`，不是签名错；错误正文是 XML（`<Code>`/`<Message>`，与华为 OBS 同构，实体如 `&lt;` 会还原成 `<` 再显示）。链接就是桶域名拼对象名，要求桶是公有读；要挂自己的 CDN 就填 `image_host_public_base`。\n- 自定义访问前缀（CDN / 加速域名）设置页里没有这一项，需要手改 `~/.markd/config.json` 的 `image_host_public_base`；填了就只替换文档里的链接前缀，写入地址仍走平台自己的端点。七牛有专门的「访问域名」输入框（`image_host_qiniu_domain`），不用改这一项；两者都填时以访问域名优先。

- 「测试上传」按钮会在后台线程上传一张测试图并回报成功 URL 或失败原因；
- 命令「上传本地图片到图床」只在命令面板里（`Cmd/Ctrl + P` 搜「图床」），用于把文档里的本地图片批量换成长期有效的公网链接。批量上传在同一个后台线程里顺序执行，每张间隔 200ms，避免被平台限流。

> ⚠️ 令牌与 AccessKey / SecretKey 以明文存在 `~/.markd/config.json`（该文件权限 0600）。这台机器上的配置不要提交进仓库、不要共享；AccessKey 建议只授予目标桶/空间的读写权限，泄露后在阿里云 RAM（或七牛「个人面板 → 证书管理」、火山引擎「访问控制 → API 访问密钥」、华为云「我的凭证 → 访问密钥」）里直接禁用重建。华为云的密钥按文档只在创建时可下载一次，每个用户最多两个，丢了只能新建；腾讯云的 SecretId / SecretKey 同样只在创建时可见，丢了只能另建一把。七牛的 SecretKey 与火山的 Secret Access Key 都只在创建时显示一次，丢了只能重新生成。

### 6.10 文件附件

| 数据 | `json` `jsonl` `xml` `yaml` `yml` `toml` `ini` `sql` `parquet` `db` `sqlite` |
| 音频 | `mp3` `wav` `flac` `ogg` `m4a` `aac` `opus` `mid` `midi` |
| 视频 | `mp4` `mov` `avi` `mkv` `webm` `flv` `wmv` `m4v` |
| 字体 | `ttf` `otf` `woff` `woff2` `eot` |

图片（`png` / `jpg`…）与 `md` 故意不算附件——前者归图片预览（[§6.7](#67-图片)），后者归应用内切标签页。扩展名先剥掉 `?查询` 与 `#锚点` 再取，所以 `https://x.com/a/b.pdf?v=2` 认得出、`https://x.com/only/path` 认不出。

**整段只有一个附件链接**才升成附件卡片；句中夹着的文件链接仍是普通链接（一句话里塞一张卡片会打断阅读）。卡片限宽 520 逻辑点并在正文列居中，含类型徽标、文件名、状态行与原始地址行（等宽字体，文件挪走或下载失败时它是唯一能复制的信息）。状态行如实写清文件此刻在哪：`电子表格 · 1.5 MB · 本地文件` / `… · 已下载到本机` / `… · 远程文件，点「下载预览」取到本机` / `… · 找不到本地文件：<解析出的路径>`。顶部功能栏是 删除 / 编辑 / 新标签页 / 打开——远程还没下载时主按钮叫「下载预览」，下载期间变「下载中…」并置灰。点文件名等于点主按钮；点卡片空白不进编辑态，要改链接按「编辑」。

预览路径分三种：本机有实体（相对路径按文档目录解析）直接交系统默认程序；远程文件先下到 `~/.markd/attachments/<地址哈希>/<文件名>`，下完自动打开并弹通知；都没有则提示找不到本地文件。下载在后台线程进行，UI 不冻结；单文件上限 512 MiB；先写 `.part` 再改名，中断只留一个被删掉的半成品，不会留下「看着已下载、实际打不开」的截断文件；按地址哈希建子目录，所以 `a.com/x/report.pdf` 与 `b.com/y/report.pdf` 不会互相冒认。

「新标签页」把地址交给系统：有本机实体（原文或已下载副本）时走 `file://`，空格与中文按 UTF-8 百分号编码；还没下下来时直接交原地址，浏览器自己完成下载。

导出 HTML 时同一个链接变成 `<div class="file-embed">`：类型、文件名、「下载」和「新标签页打开」两个链接。`download` 属性只给远程地址（本地 `file://` 链接加了它浏览器会忽略甚至报错）；本地绝对路径导出成 `file://`、相对路径保持相对。「复制为富文本」走同一段渲染，附件同样出附件条。

### 6.11 脚注、双向链接

`[^1]` 引用 + `[^1]: 定义` 自动编号并在文末汇总。`[[笔记名]]` 是双向链接：渲染成可点击链接，并被「双向链接关系图」用来画笔记之间的连接。

## 7. 导航与检索

### 7.1 命令面板（`Cmd/Ctrl + P`）

列出全部 65 条命令，输入即模糊过滤（大小写不敏感的子串匹配）。想不起快捷键、想找一个功能叫什么，都在这里搜。上下键移动、回车执行、`Esc` 关闭。

### 7.2 快速打开（`Cmd/Ctrl + Shift + O` 或 `Cmd/Ctrl + Shift + P`）

按文件名模糊查找当前工作区内的 Markdown 文件，回车打开。工作区扫描只在面板打开时进行，不在启动阶段阻塞界面。

### 7.3 文档内查找 / 替换（`Cmd/Ctrl + F`）

在当前文档内查找；`Enter` 跳到下一个、`Shift + Enter` 上一个、`Esc` 关闭。勾选正则后可用模式匹配，替换框支持 `$1`、`$2` 捕获组引用；「替换全部」一次完成并可用 `Cmd/Ctrl + Z` 整体撤销。macOS 上 `Ctrl + H`、`Cmd + Option + F` 直接进替换态。

### 7.4 工作区全文搜索（菜单「视图 → 工作区全文搜索」）

跨文件关键词搜索，结果列出文件与匹配行，回车打开对应文件。**没有默认快捷键**，可以从命令面板调出。

### 7.5 大纲（`Cmd + Ctrl + 1`，macOS）

侧栏「大纲」页签按标题层级列出当前文档，点击跳转；层级可折叠。关闭「显示行号栏」不影响大纲。

### 7.6 双向链接关系图（菜单「视图 → 双向链接关系图」）

打开面板时才在后台遍历工作区建立链接图（避免启动时长时间扫盘），完成后绘制节点与边，点击节点打开对应文件。

### 7.7 写作统计（菜单「视图 → 写作统计」）

字数、字符数、CJK 字数、行数、预计阅读时长。口径见 [§17](#17-性能表现与大文档建议)——**状态栏的「字符」是剥掉 Markdown 标记与空白后的正文字符数**，会比文件本身的字符数小约三成。

## 8. 写作模式、自动保存与快照

三种写作模式**互斥**，开一个会自动关另外两个：

| 模式 | 快捷键 | 效果 |
|---|---|---|
| 源码模式 | `Cmd/Ctrl + /` 或 `Cmd/Ctrl + E` | 整篇文档放进一个带行号的纯文本编辑器，长行不换行、横向滚动，光标行有底色 |
| 专注模式 | `F8` 或 `Cmd/Ctrl + Shift + F` | 只有当前段落保持全彩，其余淡出 |
| 打字机模式 | `F9` | 光标所在行始终保持在视口中央 |

**自动保存**：默认开启，间隔默认 20 秒（可调 5–600 秒）。只对已经落盘过的文档生效；未命名文档保持「未保存」状态，等你按保存时选路径。非活动标签里的脏文档同样按间隔写回，状态栏与标签会提示「已自动保存」。

**退出确认**：偏好设置 → 通用 → 「退出前确认」打开后，关窗时会列出所有未保存的标签，可选「保存并退出 / 不保存 / 取消」；未命名文档会让你逐个选路径。

**版本快照（时间机器）**：菜单「文件 → 版本快照 · 时间机器」打开面板，可查看与回滚历史快照，快照数据存放在 `~/.markd/snapshots/`。

## 9. 多标签、工作区与文件管理

- **多标签**：每打开一个文档占一个标签，切换时当前编辑状态被保留（各自的选区、光标、折叠）。标签栏已移除；新建走标题栏 **+**，关闭走标题栏 **×**，切换走 `Cmd/Ctrl + P` 命令面板。
- **工作区**：侧栏「文件」页签显示文件树，根目录来自「打开工作区…」或偏好设置 → 文件 → 默认工作区。扫描有 4000 文件 / 6 万条目的上限兜底，超限部分不显示。从 Finder / Dock 启动时工作区会回退到「上次目录」而不是系统根目录。
- **文件操作**：文件树上支持新建（可选择在哪个目录、带不带扩展名）、重命名、删除（确认窗）、拖到窗口打开；侧栏内还有文件级复制 / 剪贴板（粘贴到其他目录）。
- **首页**：没有可恢复文件时显示欢迎页与「最近打开」列表（最多若干条，记录在 `config.json` 的 `recent`）。

## 10. 集成终端

`Cmd/Ctrl + J` 打开 / 关闭底部终端面板。它是**真正交互式 PTY 终端**（不是逐条执行命令）：

- 启动你的登录 shell（`$SHELL`，Windows 用默认程序），支持 ANSI 彩色输出、备用屏程序（vim / less / htop）、`Ctrl+C` / 方向键 / 退格等原始控制；
- 面板尺寸变化会同步终端行列数（`SIGWINCH`），不会错位；
- 中文按双宽字符正确占列；GUI 启动缺少 `LANG` 时自动补 `en_US.UTF-8`，避免 `ls` 把中文文件名输出成 `?`；
- 终端获得焦点时，除 `Cmd/Ctrl + J` 以外的应用快捷键全部让位给 shell；macOS 上 `Cmd + C`（不带 Ctrl）复制终端选中文本，`Ctrl+C` 仍然发给 shell。

## 11. 外观、主题与字体

- **两套主题**：浅色 / 深色（对齐 VS Code Light+ / Dark+ 配色），语法高亮与公式颜色随主题切换。`菜单 → 主题 → 切换下一主题` 或主题下拉快速换。
- **自定义颜色**：偏好设置 → 外观 → 自定义颜色，14 项各带取色器与「恢复默认」：编辑区背景、侧栏背景、正文文字、次要文字、强调色、代码块背景、代码块标题栏、边框、标题、链接、引用、表头背景、表格线、选中高亮。留空即跟随当前主题。
- **字号与缩放**：正文字号 12–26 pt；界面缩放 0.8–1.6 倍（Windows 高分屏字太小时调这里）。
- **布局开关**：侧栏标签栏、工作区栏、格式工具条、行号栏各自独立可关。
- **字体**：正文优先使用**阿里巴巴普惠体 3.0**——依次扫描 `~/.markd/fonts/`、`~/Library/Fonts`、`/Library/Fonts`、`/usr/share/fonts` 等目录中文件名含 `puhuiti` 的 ttf/otf/ttc（Regular 字重优先），找不到再回退系统中文字体。代码块与行内代码始终用等宽字体，不受该设置影响。

## 12. 导出与发布

`Cmd/Ctrl + Shift + E`（或菜单「文件 → 导出 HTML」）生成**自包含 HTML**：CSS 内联，公式、代码高亮、Mermaid、表格样式都在文件内，无外部资源依赖，可直接发给别人或丢进浏览器。

- 偏好设置 → 导出 → 「导出 HTML 时内嵌图片」把本地图片转成 data URI 塞进 HTML（默认开）；关掉则保留相对路径引用。
- 「导出完成后打开文件」用系统默认浏览器打开结果。
- **PDF**：用浏览器打开导出的 HTML 后 `打印 → 存为 PDF`。设置面板里有这句提示，Markd 不内置 PDF 引擎。
- ` ```video ` 围栏导出成 `player.bilibili.com` 的 `<iframe>`（[§6.9](#69-视频哔哩哔哩)），画面由 B 站页面自己出，导出的 HTML 不含视频文件；无脚本环境退化成 B 站页面链接。
- 图片要长期外链，先配好图床（[§6.8](#68-图床把图片传到远端文档里写公网-url)），再用命令「上传本地图片到图床」替换路径，导出的 HTML 体积也就不会膨胀。
- 独占一段的附件链接导出成 `<div class="file-embed">` 附件条（[§6.10](#610-文件附件)）：远程地址给「下载」+「新标签页打开」，本地绝对路径转成 `file://`、相对路径保持相对，导出的 HTML 放在文档旁边就能直接点开同级文件。

| 文件 / 目录 | 内容 |
|---|---|
| `config.json` | 全部偏好设置、上次打开文件、最近打开列表、图床配置（含令牌 / AccessKey Secret，明文，文件权限 0600） |
| `folds.json` | 代码块折叠状态，按文档绝对路径分组、以块的源码为键 |
| `fonts/` | 自定义字体目录（优先加载 Regular 字重） |
| `assets/` | 未保存文档（还没有落盘目录）插入图片时的回退目录；正常情况图片写进**文档所在目录**下的资源子目录（默认名 `imgs`） |
| `snapshots/` | 版本快照数据，索引在 `snapshots/index.json` |

| `attachments/` | 远程附件的下载缓存，按地址哈希分子目录（`attachments/<16 位哈希>/<文件名>`），删掉只会让卡片重新出现「下载预览」，不影响文档 |
删掉 `config.json` 相当于恢复出厂：下次启动按首次启动对待（空白文档、收起侧栏与工具条）。

## 17. 性能表现与大文档建议

**统计口径**：状态栏与写作统计里的「字符」= 各块**剥掉 Markdown 标记后**的非空白字符数，因此它会明显小于文件字符数（一份混排文档大约是其 70–75%）。「字数」= 按空白切词的词数 + 每个 CJK 字符计 1。

**实测**（1000 万字级文档：241,877 块 / 17.6 MB 的混排语料，release 构建，1280px 视口）：首帧 34.8 ms、静置 1.5 ms、滚动 5.5 ms、敲字 2.7 ms、每帧绘制图元 182、常驻 271 MB；打开时解析约 550 ms。原理是**每帧只排版落在视口内的块**（块高表 + 二分定位），所以帧成本与文档总长无关。

大文档使用建议：

- 编辑优先留在混合模式。源码模式会把整篇文本一次性交给 egui 排版：千万字级冷首帧需要数秒，且每次改动都重新解析整篇（约 1 秒/键）。
- 查找用 `Cmd/Ctrl + F`（命中扫描已并行，千万字约 20–30 ms）；跨文件搜索请在工作区里用「工作区全文搜索」。
- 保存与导出：导出一份千万字 HTML 需要数秒（43 MB 输出），完成后按需勾选自动打开。
- 撤销栈只存块级差量，连续输入不会让内存随文档长度线性上涨；上限 200 组。

## 18. 使用场景配方

### 18.1 课程 / 技术学习笔记

1. 把笔记目录作为工作区（菜单「文件 → 打开工作区…」），侧栏「文件」页签树形浏览；
2. 每篇笔记顶部写 `# 标题`，用 `[TOC]` 生成目录；
3. 公式走 `$…$` 与 `$$…$$`，代码走带语言标记的围栏代码块（同一份代码的多语言版本用「代码组」）；
4. 跨笔记引用写 `[[另一篇笔记]]`，需要看整体结构时打开「双向链接关系图」；
5. 想通读时按 `F8` 专注模式，边看边补时关掉。

### 18.2 周报 / 日记

1. 一个目录按日期放文件，`Cmd/Ctrl + Shift + O` 输入 `11-19` 直接跳；
2. 待办用任务列表（`Cmd + Option + X`），渲染态点框即勾；
3. 打开自动保存（默认就开着，20 秒一次），忘记按 `Cmd+S` 也不丢；
4. 每天收尾用「版本快照 · 时间机器」留一份，改错了随时回滚。

### 18.3 项目文档 / README

1. 直接编辑仓库里的 `README.md`：代码块高亮、表格、图片、徽章都能所见即所得地写；
2. 截图 `Cmd+V` 落盘到 `imgs/`，写成相对路径（提交进仓库）或图床 URL（不想把大图提交进 git 时）；
3. 发布前 `Cmd/Ctrl + Shift + E` 导出一份自包含 HTML 给非技术同事看，或让浏览器打印成 PDF。

### 18.4 长文写作 / 论文草稿

1. 偏好设置把界面缩放调到 1.2、正文字号 18–20，读起来省力；
2. 打字机模式 `F9` 让当前行始终居中，专注模式 `F8` 压暗其它段落；
3. 结构靠大纲：`Cmd + Ctrl + 1` 打开，点标题在章节之间跳；
4. 引文与注释用脚注 `[^1]`，参考文献列表放文末段落，导出 HTML 时保留编号。

### 18.5 整理旧笔记

1. 「工作区全文搜索」找散落各文件的关键词，回车打开；
2. 进入文档后用 `Cmd/Ctrl + F` 勾选正则批量改写（例如把 `img/` 统一成 `imgs/`，替换框写 `$1` 保留捕获内容）；
3. 替换结果异常立刻 `Cmd/Ctrl + Z` 整体撤销；
4. 文件重命名 / 移动在侧栏文件树里做，双链关系图随后会反映新名字。

### 18.6 边查资料边写（终端）

`Cmd/Ctrl + J` 打开终端：`git status`、`ls`、`rg 关键词`、甚至 `vim`（备用屏与颜色都正常）都能在同一个窗口里跑；点回正文即恢复编辑，`Cmd/Ctrl + J` 收起面板。

## 19. 常见问题

**快捷键按了没反应？**
先看焦点在哪：终端面板有焦点时，除 `Cmd/Ctrl + J` 外所有应用快捷键都会让位给 shell。若确实要点两次才生效，通常是鼠标在按住期间有轻微位移——已经把「点击」判定放宽（10 px / 1.5 s），若仍复现，请记录具体位置。

**中文显示成方块 / 乱码？**
正文优先找阿里巴巴普惠体 3.0；把它放进 `~/.markd/fonts/`（文件名含 `puhuiti`）后重启。终端里中文变 `?` 是 locale 问题，应用已在缺 `LANG` 时补 `en_US.UTF-8`，若你的 shell 自己覆盖了 `LANG`，改回 UTF-8 变体。

**图片显示「图片未找到」？**
路径是相对当前文档所在目录解析的；检查文件是否被移动、或者写的是绝对路径 / 图床 URL。远端 URL 会显示「正在加载图片」，失败时退回占位框，重新滚动进入视口即可重试。

**公式没渲染出来？**
确认偏好设置 → Markdown → 数学公式已开启；行内 `$…$` 要求两侧成对，块级用独立成段的 `$$…$$` 或 ` ```math ` 代码块。

**`$` 被误认成公式（比如写价格）？**
关掉「数学公式」开关，或者用 `\$` 转义。

**导出的 HTML 图片看不到？**
关闭「导出 HTML 时内嵌图片」时导出的是相对路径引用，需要连同图片目录一起分发；单文件分享就把它打开。

**关系图 / 全文搜索一片空白？**
说明还没有工作区（或工作区里没有别的 Markdown 文件）。先用「文件 → 打开工作区…」指到笔记根目录；关系图是打开面板后才在后台扫描的，稍等片刻。

**想彻底回到初始状态？**
删除（或改名）`~/.markd/config.json`，重启即按首次启动处理。想连折叠与快照一起清掉，再删 `folds.json` 与 `snapshots/`。

**大文档变卡了？**
先确认是不是在源码模式（每键整篇重解析）。混合模式下帧成本与文档长度无关；若确实出现持续掉帧，记录文档规模与正在执行的操作，这是需要修的信息。

**多显示器之间窗口字太小？**
用「界面缩放」调，而不是改系统 DPI；缩放范围 0.8–1.6。

**图床上传失败？**
「测试上传」按钮会给出具体错误。常见原因是凭证权限不足（GitHub 回 403 = 令牌的 Contents 没给写权限；OSS 回 403 = AccessKey 没写权限，或本机时钟与标准时间差了 15 分钟以上导致签名失效；七牛回 401 = AccessKey/SecretKey 不对，或本机时钟不准让刚签的凭证一出生就过期）、百度回 `AccessDenied` 是桶没设公共读或这把密钥没有写入权限，回 `NoSuchBucket` 是桶名与地域没配对，回 `SignatureDoesNotMatch` 是 SecretKey 不对或本机时钟偏了（信任状 1800 秒过期）；注意 `MissingDateHeader` 不该出现，出现了说明是 Markd 自己的缺陷、请反馈或升级、仓库/桶或分支不存在（GitHub 回 404、OSS 回 404 说明桶名或地域不对）、区域与空间不匹配（七牛回 400，错误里会直接写出该用哪个上传域名，例如 `incorrect region, please use up-z2.qiniup.com`——照它改「区域」即可；火山回 `InvalidAccessKeyId` 是这把 AccessKey 在火山那边查不到（先在控制台核对：取自「访问控制 → API 访问密钥」、状态「启用」、与桶同账号），回 `AccessDenied` 是没有该桶的 PutObject 权限，回 `NoSuchBucket` 是桶名与地域没配对；华为回 `SignatureDoesNotMatch` 是秘密访问密钥不对或本机时钟偏了 15 分钟以上（对象名该编码的地方没编码也会走到这一条），回 `InvalidAccessKeyId` 是这把密钥在华为查不到（核对「我的凭证 → 访问密钥」，并与桶同账号），回 `NoSuchBucket` 也是桶名与区域没配对；腾讯回 `SignatureDoesNotMatch` 是 SecretKey 不对、或对象名被多编码了一次（本平台恰恰要求**原样**签），回 `AccessDenied` + `Request has expired` 是本机时钟偏了（签名时间窗 10000 秒），回 `InvalidRequest` 且原话提到 `Appid` 是桶名漏了 `-APPID` 后缀，回 `InvalidAccessKeyId` 是这把 SecretId 在腾讯云查不到，回 `NoSuchBucket` 是桶名与地域没配对）、目录路径模板写了非法字符。上传失败时本地图片仍在，文档链接不会被改坏。七牛用测试域名（`*.clouddn.com`）时链接是 `http://`：这是七牛没给测试域名配 HTTPS 证书（实测 https 回 421），不是 Markd 写错。

## 20. 已知限制

- **表格没有增删行列的图形化菜单**：结构改动要进源码态改分隔行与竖线。
- **源码模式在大文档上代价高**：冷首帧数秒、每键整篇重解析（约 1 秒 / 键）。混合模式不受影响。
- **PDF 需要借道浏览器打印**，没有内置排版引擎。
- **图床目前支持 Gitee 仓库、GitHub 仓库、阿里云 OSS、七牛云 Kodo、火山引擎 TOS、百度智能云 BOS、华为云 OBS 与腾讯云 COS**（其它平台需要新增适配）；令牌与 AccessKey / SecretKey 明文保存在本地配置里。GitHub 走 Contents API，每张图一次提交；OSS 要求桶是公共读，否则文档里的链接公网打不开；七牛走表单上传（实测 5MB 单文件也没问题），空间是私有读时同样只能靠签名下载地址。单图上限 20MB。
- **对象名带空格、`#` 或中文时，编辑器里的远程图片预览不出来**：上传与文档链接都正常（浏览器会自己补编码），但预览用的是链接原样，实测这种 URL 取不回图，改成百分号编码后的地址就能取回。默认命名（`{filename}` 只留字母数字与 `-`/`_`）不会触发；把「目录」填成中文或带空格就会。修法要在预览处补一层编码，又不能把本来就带 `%XX` 的旧链接二次编码，涉及所有平台的既有链接，暂未动。：图片极多的文档长时间翻阅内存会持续上升，重开文档释放。
- **超长引用点进编辑态后，换行点会挪一点点**：渲染态的行宽用满正文宽度，编辑态的输入框给光标留了 8px，所以一段需要软换行的长引用在编辑态可能提前一个字符换行。左侧竖线和文字起点都不动，动的只是断在哪里。
- **不支持协作、批注、插件系统**。
- **附件靠系统默认程序打开，应用内不渲染内容**：Markd 只负责把文件取到本机再交出去，不内置 PDF 查看器或 Office 渲染；导出 HTML 同理给的是链接，不是文件本体。
- **本地附件只写引用，不复制进文档目录**：与图片默认复制进 `imgs` 相反——几十 MB 的附件复制进工作区会拖慢保存，也不该由编辑器搬用户的文件。于是文件挪走或换机就断链，卡片会老实显示「找不到本地文件：<解析出的路径>」；分享文档要自己把附件一起带走。
- **远程附件要认得出扩展名**：无扩展名的直链（`…/download?id=7`）不会被认成附件，仍是普通链接；需要登录或私有读的地址下载会失败并把服务端原话写进通知；单文件上限 512 MiB，超过按失败处理，不会把磁盘写满。
- 内容完全相同的两个代码块会共享同一条折叠记录（折叠状态以源码文本为键）。
- 工作区文件树有 4000 文件 / 6 万条目上限，超限的目录不会显示。
