## 1. 十分钟上手

**安装**：从 [Releases](https://github.com/whboy10000/markd/releases/latest) 下载对应平台的安装包。

- macOS：`Markd-*-macos-universal.dmg`（通用）或按芯片选 intel / apple-silicon；打开后把 Markd 拖进「应用程序」。首次运行若提示「无法验证开发者」，执行 `xattr -d com.apple.quarantine /Applications/Markd.app`。
- Windows：`Markd-*-windows-setup.exe`，安装向导中可勾选创建桌面与开始菜单快捷方式。
- Linux：`Markd-*-linux-amd64.deb`（`sudo dpkg -i`）或 `.rpm`（`sudo rpm -i`），两者都会注册应用菜单项；也可以解压 `.tar.gz` 直接跑二进制。

**第一次打开**（全新配置，未写过 `~/.markd/config.json`）会直接给你一个空白文档，并且默认收起侧栏、大纲与格式工具条——界面只有编辑区，先写起来。之后再次启动时：

1. `Cmd/Ctrl + O` 浏览文件，或 `Cmd/Ctrl + Shift + O` 在当前工作区里按名字快速找文件；
2. 直接把 `.md` 文件从 Finder / 资源管理器**拖到窗口**里也能打开；
3. 开始输入：默认所有文本都是段落，用 `Cmd/Ctrl + 1…6` 变成各级标题，`Cmd/Ctrl + 0` 变回段落；
4. `Cmd/Ctrl + S` 保存。文档还没落盘过时会弹出「另存为」让你选位置，之后每次 `Cmd/Ctrl + S` 直接写回原文件；
5. 想临时看 Markdown 源码，按 `Cmd/Ctrl + /`（或 `Cmd/Ctrl + E`）切到源码模式，再按一次切回。

关掉首个文档后，之后的启动会按「启动时恢复上次打开的文件」设置恢复现场；没有可恢复文件时显示首页（欢迎页 + 最近打开列表）。

自上而下、从左到右：

| 区域 | 内容 | 开/关方式 |
|---|---|---|
| 标题栏（macOS 为窗口内容顶部一行） | 文档标题（文件名，未保存时带标记）、右侧固定「保存」与 `>_`（终端）按钮；空白处可拖动窗口 | 由窗口样式决定 |
| 菜单栏 | macOS 使用**系统原生菜单栏**（屏幕最左上角）；Windows / Linux 在窗口内显示「文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 窗口 / 帮助」 | 见 [§15](#15-菜单结构) |
| 格式工具条 | 撤销 / 重做、**标题**下拉、`B` / `U` / `I` / `ABC`（下划线、斜体、删除线按字形示意）、**列表**下拉、引用 / 图片 / 超链接、**公式** / **代码** / **插入** / **Mermaid** 四个下拉（见 [§6.3](#63-表格)、[§6.4](#64-代码块与代码组)、[§6.5](#65-数学公式)）；分隔线右侧是「快照 / 关系图 / 统计」与放大镜（= `Cmd/Ctrl + F`） | 偏好设置 → 外观 → 显示格式工具条 |

| 侧栏 | 两个页签：**文件**（工作区文件树）与**大纲**（当前文档标题树）；右缘可拖动改变宽度 | `Cmd/Ctrl + Shift + L` 显隐；`Cmd + Ctrl + 1`（macOS）切到大纲 |
| 工作区栏 | 顶部显示当前工作区路径，可直接输入路径切换 | 偏好设置 → 外观 → 显示工作区栏（默认关） |
| 编辑区 | Hybrid View 正文 | — |
| 终端面板 | 底部可拖动的 PTY 终端 | `Cmd/Ctrl + J` |
| 状态栏 | 光标位置、字数统计、「文件 / 大纲」两个侧栏入口 | — |

首次启动时侧栏、大纲、工具条都是关的，需要自己在「偏好设置 → 外观」或「视图」菜单里打开。

## 3. 核心概念：Hybrid View

**当前正在编辑的块显示 Markdown 源码，其余块实时渲染成富文本。**

- 鼠标点进一个段落，它就变成源码编辑框，你能精确看到并修改 `**`、缩进、空行、标记顺序；
- 焦点离开（点到别处、按方向键移出），它立刻回到渲染态；
- 因此源文件里的细节不会被自动格式化「吃掉」——Markd 不做「解析成 AST 再重新打印」，写回磁盘的就是你输入的字节。

块 = 一个标题 / 段落 / 引用 / 列表项 / 表格 / 代码块 / 公式 / Mermaid / 图片 / 分隔线 / 空行。这个概念决定了几个日常行为：

- 光标行高亮、行号都是**按块**给出的；
- 「插入表格 / 公式 / 代码块」等命令作用于**当前块所在处**；
- 代码块、表格、公式这类复杂块在渲染态下是「只读展示」，要改内容必须点进去（或用源码模式）。

## 4. 文本编辑基础

| 操作 | 行为 |
|---|---|
| `Enter` | 在当前块内换行；位于块尾时新建下一块（编辑态由块的类型决定标题 / 代码块等特殊行为） |
| `Backspace` 于行首 | 与前一块合并。**例外**：代码块 / 图表 / 代码组这类带 ` ``` ` 围栏的块不动光标、不并块（否则一个退格就把整块代码打回普通文字）；要退出这种块，在空块里连按两次 `Enter`，或点块头「删除」 |
| `↑` / `↓` | 跨块移动光标，到块边界自动切到相邻块 |
| `Tab` / `Shift + Tab` | 列表项内：增加 / 减少一级缩进（步长 = 偏好设置里的 Tab 宽度）；非列表块内：插入缩进 |
| 鼠标拖选 | 支持从标题拖进段落、跨越代码块 / 图片 / 公式的**跨块选区**；拖拽期间活动块保持编辑态，避免布局跳动 |
| `Cmd/Ctrl` + 单击链接 | 打开链接；不带修饰键单击不会误触发（编辑态内尤其重要） |
| 右键 | 上下文菜单：剪切 / 拷贝 / 粘贴，以及「段落 / 格式 / 插入」子菜单；「复制为 / 粘贴为」支持 Markdown、纯文本、HTML 三种目标 |
| `Cmd/Ctrl + C` / `X` | 复制 / 剪切，剪贴板同时写入**带格式 HTML**，粘贴进 Word / 浏览器保留样式 |
| `Cmd/Ctrl + V`（剪贴板里是图片） | 自动把截图落盘到资源目录并插入图片链接 |
| `Cmd/Ctrl + Z` / `Shift + Z` | 撤销 / 重做。记录按块存差量，连续输入按 450 ms 合并成一组，上限 200 组 |
| 拖拽文件到编辑区 | 打开该文件 |

删除代码块与表格会弹确认窗（这两类块内容多，误删代价大）。

## 5. Markdown 语法支持

**块级**

| 写法 | 说明 |
|---|---|
| `#` … `######` | ATX 标题（1–6 级）；`文本` 下加 `===` / `---` 为 Setext 一 / 二级标题 |
| 空行分隔 | 段落切分 |
| `>`、`> >` | 引用，支持嵌套块；点进去编辑时左侧竖线与文字起点都不移动 |
| `- item` / `* item` / `1. item` | 无序 / 有序列表，两空格缩进表示嵌套 |
| `- [ ]` / `- [x]` | 任务列表，渲染态可直接点选勾选 |
| `---` / `***` | 分隔线 |
| ` ```lang ` … ` ``` ` | 围栏代码块，`lang` 决定高亮语言与代码组标签 |
| `\| 列 \| 列 \|` + `---` 行 | 表格，`---:` / `:---:` / `:---:` 控制右 / 左 / 对齐 |
| `[^1]` 与 `[^1]: 内容` | 脚注引用与定义，自动编号 |
| 文件顶部 `---` … `---` | YAML Front Matter，以代码块面板呈现（语言固定 `yaml`），不混入正文 |
| `[TOC]` | 就地插入目录（可在偏好设置里整体关掉） |

**行内**

`**粗体**`、`*斜体*`、`__下划线__`、`~~删除线~~`、`==高亮==`、`` `行内代码` ``、`上标/下标`、`[文字](url)`、`![alt](src)`、`<http://自动链接>`、`$行内公式$`、`[[双向链接]]`、`\` 硬换行。行内标记可以嵌套混用（如 `**加粗里带==高亮==**`）。

导出 HTML 与「复制为 HTML」使用同一套渲染结果，所见即所得。

## 6. 内容块详解

### 6.1 标题与目录

`Cmd/Ctrl + 1…6` 设级别，`Cmd/Ctrl + 0` 变回段落。偏好设置 → Markdown → **标题自动编号**打开后，预览里各级标题按 `1.` / `1.2` / `1.2.3` 显示编号（只影响显示，不写进文件）。`[TOC]` 块渲染成可点击目录，点击跳转到对应标题。

### 6.2 列表与任务

无序 / 有序 / 任务列表在渲染态可以直接点勾选框。缩进层级会体现在导出的 HTML 与嵌套渲染上。改变层级用 `Tab` / `Shift + Tab`，或插入两个空格。

### 6.3 表格

`Cmd/Ctrl + Option + T`（macOS）/ `Ctrl + Alt + T` 或菜单「段落 → 插入表格」弹出对话框，输入行列数（默认 3×3）。对话框在**正文区正中**弹出，不再停在左上角。插入后点表格进入源码态编辑单元格文本；对齐符号写在分隔行里（`|:---|---:|`）。表格宽度自适应正文区宽度，超宽时横向滚动。

需要输入或确认的模态对话框一律居中且不可拖动：插入表格、插入链接、新建文件/新建文件夹、重命名、删除确认、打开工作区，另外「有未保存的修改」也是同款。「关于 Markd」「快捷键一览」是参考面板（后者内容比窗口还高），保持可拖动、不居中。

### 6.4 代码块与代码组

插入：`Cmd + Option + C`（macOS）/ `Ctrl + Alt + C`，菜单「段落 → 插入代码块」，或工具条**「代码」下拉**里的「代码块」（该下拉三项依次是「行内代码 / 代码块 / 代码组」，和 [§6.5](#65-数学公式) 的「公式」下拉同款收法）。渲染态头部一条功能栏：

- 左侧是**语言标签下拉**，换语言立刻改变高亮；
- 右侧依次是**复制**、**删除**（弹确认）、**折叠 / 展开**。折叠状态按代码块的**源码文本**记录，写入 `~/.markd/folds.json`，重启后保持（内容相同的两块会共享折叠状态）。

代码区支持行号与当前行高亮（受「显示行号栏」开关控制）。语言下拉有 **460+ 行**：规范名和它的每个别名**各占一行**，覆盖主流语言、脚本与命令行、配置与 IaC、数据库方言、着色器与硬件、函数式与学术语言、排版与图表 DSL。所以 `cpp` 与 `c++`/`cxx`/`cc` 都能在列表里点到，`dart` 与 `flutter` 都在，`yaml` 与 `yml`/`k8s`/`helm`/`github-actions`/`docker-compose` 都在，`go` 与 `golang`、`csharp` 与 `c#`、`bash` 与 `shell`/`shell-session` 同理。**点哪一行就把哪一行原样写进围栏信息行**，别名行悬停会提示「与 `dart` 等价」；两种写法的高亮效果完全一致（解析按小写键，手写 ```` ```CPP ````、```` ```C++ ```` 也认）。输入框实时过滤、大小写不敏感，纯文本始终排在第一行。

语法高亮仍是自研词法着色，分三层决定效果：

- **配色族** 10 个：Rust、Python、JavaScript/TypeScript、C 系（C/C++/Java/Go/Kotlin/Swift/Dart/Rust 之外的 `//` 系语言）、Markup（HTML/XML/模板）、CSS、数据格式（JSON/YAML/TOML/INI）、Shell、SQL、通用回退；
- **注释语法按语言**给出，而不是跟着配色族：`//`、`#`、`--`、`%`、`;`、`!`、`::` / `rem`、`dnl`、`\*`、`%%`，块注释支持 `/* */`、`<!-- -->`、`{- -}`、`(* *)`、`{ }`、`--[[ ]]`、`#= =#`、`(: :)`；正文型语言（Markdown/纯文本/CSV/diff/LaTeX 正文）不启用 `//`，链接里的 `//` 不会被染成注释；
- **关键字表**：通用表按族取用，Dockerfile、Makefile、CMake、Terraform/HCL、Nginx、Lua、Haskell、Ruby、Go、LaTeX、MATLAB、Julia、R、Elixir、Clojure、Solidity、GraphQL 另有一张专属表，避免把别族的关键字误标或漏标。

**YAML Front Matter 用同一个代码面板渲染**：文件顶部的 `---` … `---` 块显示成与普通代码块同款的功能栏 + 高亮区，语言位是固定的 `yaml` 标签（不可更改——改语言对 front matter 没有意义），折叠 / 删除 / 复制、折叠动画、点击进编辑态都与代码块一致。「复制」取到的是两行 `---` 之间的 YAML 正文；源码里的 `---` 边界、导出 HTML 的 front matter 处理、大纲归类都不受这次外观变化影响。点进编辑态时仍是含 `---` 的原始文本且不逐字高亮：编辑 front matter 必须看得见、也删得掉那两行边界。

**代码组**（菜单「段落 → 插入代码组（多语言 Tab）」，或工具条「代码」下拉的第三项）把同一算法的多语言实现放进一个块，渲染成可切换的 Tab；导出 HTML 时保留 Tab 切换。

代码块末尾回车行为对齐 Typora：在最后一行行尾回车新建一行；在末尾空行上再回车则退出代码块、在其下方插入普通段落。

代码块里的鼠标与退格：

- **点哪个字符，光标就落在哪个字符**（包括第一行第一个字符），不会跳到整段代码末尾；
- 按住拖动只选中**指针经过的那几行**，不会一下子整块选中；拖动途中指针飘到功能栏或面板留白，端点仍跟着指针走；
- **光标在第一行第一个字符按 `Backspace` 什么都不发生**：代码块 / 图表 / 代码组不会被退格并回上一块，正文删到空也只留一个空代码块，围栏不会丢。要把这种块去掉，用块头「删除」或在空块里连按两次 `Enter`。

### 6.5 数学公式

三种写法：行内 `$E=mc^2$`、块级 `$$ ... $$`、代码块 ` ```math `。工具条上它们收在**一个「公式」下拉**里，三项依次是「行内公式 / 公式块 / 代码块公式」（不再各占一个平铺按钮）；原生菜单里同名的三项在「段落」菜单下。

公式由 RaTeX 排成显示列表，再由 Markd 细分成三角形直接交给 GPU 绘制：**不生成 PNG、不走纹理**，所以放大不失真、颜色跟随主题。行内公式按文字基线对齐；块级公式居中、超宽时等比缩小。行内自动用 `\textstyle`、块级用 `\displaystyle`，与 LaTeX 一致。渲染结果按 `(公式, 字号, 显示模式)` 缓存。

不想让 `$` 被当公式解析时，在偏好设置 → Markdown 里关掉「数学公式」。

### 6.6 Mermaid 与流程图

菜单「段落 → 插入 Mermaid 图」给带模板的选择器，「插入流程图」直接给 flowchart 模板。约 25 种图各由独立的 Rust 渲染器绘制（不用 mermaid.js）：flowchart、sequence、class、er、gantt、journey、gitGraph、mindmap、timeline、pie、quadrantChart、radar、sankey、treemap、xychart、kanban、C4、requirementDiagram、cynefin、packet、railroad、swimlane、blockDiagram、boxes 等。开关在偏好设置 → Markdown → 「Mermaid / 流程图」。

### 6.7 图片

三种进入文档的方式：

1. **粘贴截图**：`Cmd/Ctrl + V` 时若剪贴板是图片，自动写入资源目录并插入 `![...](路径)`；
2. **菜单 / `Cmd + Ctrl + I`（macOS）**：选文件插入；
3. **拖拽图片文件到编辑区**。

路径规则由偏好设置 → 图像控制：是否复制进资源目录（默认开，目录名默认 `imgs`）、使用相对路径还是绝对路径。显示上限制最大宽度不超过正文、最大高度不超过视口 60%，水平居中；悬停时右下角出现手柄，**拖动即可缩放**，缩放值以 `{width=N}` 属性写回源码，导出 HTML 时变成 `<img width="N">`。

`http(s)` 图片会在后台线程下载并缓存成纹理，文档里直接写图床 URL 就能阅读；下载期间显示「正在加载图片」，失败或本地文件缺失显示「图片未找到」占位框。

### 6.8 图床（把图片传到远端，文档里写公网 URL）

偏好设置 → 图像 → 图床，平台选「Gitee 仓库」，填：用户名、仓库、分支、目录、保存路径模板（支持 `{year}` `{month}` `{day}` `{hour}` `{minute}` 占位符，默认 `{year}/{month}/{day}`）、私人令牌。

- 「测试上传」按钮会在后台线程上传一张测试图并回报成功 URL 或失败原因；
- 命令「上传本地图片到图床」只在命令面板里（`Cmd/Ctrl + P` 搜「图床」），用于把文档里的本地图片批量换成长期有效的公网链接。

> ⚠️ 令牌以明文存在 `~/.markd/config.json`。这台机器上的配置不要提交进仓库、不要共享。

### 6.9 脚注、双向链接

`[^1]` 引用 + `[^1]: 定义` 自动编号并在文末汇总。`[[笔记名]]` 是双向链接：渲染成可点击链接，并被「双向链接关系图」用来画笔记之间的连接。

## 7. 导航与检索

### 7.1 命令面板（`Cmd/Ctrl + P`）

列出全部 65 条命令，输入即模糊过滤（大小写不敏感的子串匹配）。想不起快捷键、想找一个功能叫什么，都在这里搜。上下键移动、回车执行、`Esc` 关闭。

### 7.2 快速打开（`Cmd/Ctrl + Shift + O` 或 `Cmd/Ctrl + Shift + P`）

按文件名模糊查找当前工作区内的 Markdown 文件，回车打开。工作区扫描只在面板打开时进行，不在启动阶段阻塞界面。

### 7.3 文档内查找 / 替换（`Cmd/Ctrl + F`）

在当前文档内查找；`Enter` 跳到下一个、`Shift + Enter` 上一个、`Esc` 关闭。勾选正则后可用模式匹配，替换框支持 `$1`、`$2` 捕获组引用；「替换全部」一次完成并可用 `Cmd/Ctrl + Z` 整体撤销。macOS 上 `Ctrl + H`、`Cmd + Option + F` 直接进替换态。

### 7.4 工作区全文搜索（菜单「视图 → 工作区全文搜索」）

跨文件关键词搜索，结果列出文件与匹配行，回车打开对应文件。**没有默认快捷键**，可以从命令面板调出。

### 7.5 大纲（`Cmd + Ctrl + 1`，macOS）

侧栏「大纲」页签按标题层级列出当前文档，点击跳转；层级可折叠。关闭「显示行号栏」不影响大纲。

### 7.6 双向链接关系图（菜单「视图 → 双向链接关系图」）

打开面板时才在后台遍历工作区建立链接图（避免启动时长时间扫盘），完成后绘制节点与边，点击节点打开对应文件。

### 7.7 写作统计（菜单「视图 → 写作统计」）

字数、字符数、CJK 字数、行数、预计阅读时长。口径见 [§17](#17-性能表现与大文档建议)——**状态栏的「字符」是剥掉 Markdown 标记与空白后的正文字符数**，会比文件本身的字符数小约三成。

## 8. 写作模式、自动保存与快照

三种写作模式**互斥**，开一个会自动关另外两个：

| 模式 | 快捷键 | 效果 |
|---|---|---|
| 源码模式 | `Cmd/Ctrl + /` 或 `Cmd/Ctrl + E` | 整篇文档放进一个带行号的纯文本编辑器，长行不换行、横向滚动，光标行有底色 |
| 专注模式 | `F8` 或 `Cmd/Ctrl + Shift + F` | 只有当前段落保持全彩，其余淡出 |
| 打字机模式 | `F9` | 光标所在行始终保持在视口中央 |

**自动保存**：默认开启，间隔默认 20 秒（可调 5–600 秒）。只对已经落盘过的文档生效；未命名文档保持「未保存」状态，等你按保存时选路径。非活动标签里的脏文档同样按间隔写回，状态栏与标签会提示「已自动保存」。

**退出确认**：偏好设置 → 通用 → 「退出前确认」打开后，关窗时会列出所有未保存的标签，可选「保存并退出 / 不保存 / 取消」；未命名文档会让你逐个选路径。

**版本快照（时间机器）**：菜单「文件 → 版本快照 · 时间机器」打开面板，可查看与回滚历史快照，快照数据存放在 `~/.markd/snapshots/`。

## 9. 多标签、工作区与文件管理

- **多标签**：每打开一个文档占一个标签，脏状态在标签上可见。切换标签时当前编辑状态被保留（各自的选区、光标、折叠）。标签栏可在偏好设置里关掉。
- **工作区**：侧栏「文件」页签显示文件树，根目录来自「打开工作区…」或偏好设置 → 文件 → 默认工作区。扫描有 4000 文件 / 6 万条目的上限兜底，超限部分不显示。从 Finder / Dock 启动时工作区会回退到「上次目录」而不是系统根目录。
- **文件操作**：文件树上支持新建（可选择在哪个目录、带不带扩展名）、重命名、删除（确认窗）、拖到窗口打开；侧栏内还有文件级复制 / 剪贴板（粘贴到其他目录）。
- **首页**：没有可恢复文件时显示欢迎页与「最近打开」列表（最多若干条，记录在 `config.json` 的 `recent`）。

## 10. 集成终端

`Cmd/Ctrl + J` 打开 / 关闭底部终端面板。它是**真正交互式 PTY 终端**（不是逐条执行命令）：

- 启动你的登录 shell（`$SHELL`，Windows 用默认程序），支持 ANSI 彩色输出、备用屏程序（vim / less / htop）、`Ctrl+C` / 方向键 / 退格等原始控制；
- 面板尺寸变化会同步终端行列数（`SIGWINCH`），不会错位；
- 中文按双宽字符正确占列；GUI 启动缺少 `LANG` 时自动补 `en_US.UTF-8`，避免 `ls` 把中文文件名输出成 `?`；
- 终端获得焦点时，除 `Cmd/Ctrl + J` 以外的应用快捷键全部让位给 shell；macOS 上 `Cmd + C`（不带 Ctrl）复制终端选中文本，`Ctrl+C` 仍然发给 shell。

## 11. 外观、主题与字体

- **两套主题**：浅色 / 深色（对齐 VS Code Light+ / Dark+ 配色），语法高亮与公式颜色随主题切换。`菜单 → 主题 → 切换下一主题` 或主题下拉快速换。
- **自定义颜色**：偏好设置 → 外观 → 自定义颜色，14 项各带取色器与「恢复默认」：编辑区背景、侧栏背景、正文文字、次要文字、强调色、代码块背景、代码块标题栏、边框、标题、链接、引用、表头背景、表格线、选中高亮。留空即跟随当前主题。
- **字号与缩放**：正文字号 12–26 pt；界面缩放 0.8–1.6 倍（Windows 高分屏字太小时调这里）。
- **布局开关**：侧栏标签栏、工作区栏、格式工具条、标签栏、行号栏各自独立可关。
- **字体**：正文优先使用**阿里巴巴普惠体 3.0**——依次扫描 `~/.markd/fonts/`、`~/Library/Fonts`、`/Library/Fonts`、`/usr/share/fonts` 等目录中文件名含 `puhuiti` 的 ttf/otf/ttc（Regular 字重优先），找不到再回退系统中文字体。代码块与行内代码始终用等宽字体，不受该设置影响。

## 12. 导出与发布

`Cmd/Ctrl + Shift + E`（或菜单「文件 → 导出 HTML」）生成**自包含 HTML**：CSS 内联，公式、代码高亮、Mermaid、表格样式都在文件内，无外部资源依赖，可直接发给别人或丢进浏览器。

- 偏好设置 → 导出 → 「导出 HTML 时内嵌图片」把本地图片转成 data URI 塞进 HTML（默认开）；关掉则保留相对路径引用。
- 「导出完成后打开文件」用系统默认浏览器打开结果。
- **PDF**：用浏览器打开导出的 HTML 后 `打印 → 存为 PDF`。设置面板里有这句提示，Markd 不内置 PDF 引擎。
- 图片要长期外链，先配好图床（[§6.8](#68-图床把图片传到远端文档里写公网-url)），再用命令「上传本地图片到图床」替换路径，导出的 HTML 体积也就不会膨胀。

## 17. 性能表现与大文档建议

**统计口径**：状态栏与写作统计里的「字符」= 各块**剥掉 Markdown 标记后**的非空白字符数，因此它会明显小于文件字符数（一份混排文档大约是其 70–75%）。「字数」= 按空白切词的词数 + 每个 CJK 字符计 1。

**实测**（1000 万字级文档：241,877 块 / 17.6 MB 的混排语料，release 构建，1280px 视口）：首帧 34.8 ms、静置 1.5 ms、滚动 5.5 ms、敲字 2.7 ms、每帧绘制图元 182、常驻 271 MB；打开时解析约 550 ms。原理是**每帧只排版落在视口内的块**（块高表 + 二分定位），所以帧成本与文档总长无关。

大文档使用建议：

- 编辑优先留在混合模式。源码模式会把整篇文本一次性交给 egui 排版：千万字级冷首帧需要数秒，且每次改动都重新解析整篇（约 1 秒/键）。
- 查找用 `Cmd/Ctrl + F`（命中扫描已并行，千万字约 20–30 ms）；跨文件搜索请在工作区里用「工作区全文搜索」。
- 保存与导出：导出一份千万字 HTML 需要数秒（43 MB 输出），完成后按需勾选自动打开。
- 撤销栈只存块级差量，连续输入不会让内存随文档长度线性上涨；上限 200 组。

## 18. 使用场景配方

### 18.1 课程 / 技术学习笔记

1. 把笔记目录作为工作区（菜单「文件 → 打开工作区…」），侧栏「文件」页签树形浏览；
2. 每篇笔记顶部写 `# 标题`，用 `[TOC]` 生成目录；
3. 公式走 `$…$` 与 `$$…$$`，代码走带语言标记的围栏代码块（同一份代码的多语言版本用「代码组」）；
4. 跨笔记引用写 `[[另一篇笔记]]`，需要看整体结构时打开「双向链接关系图」；
5. 想通读时按 `F8` 专注模式，边看边补时关掉。

### 18.2 周报 / 日记

1. 一个目录按日期放文件，`Cmd/Ctrl + Shift + O` 输入 `11-19` 直接跳；
2. 待办用任务列表（`Cmd + Option + X`），渲染态点框即勾；
3. 打开自动保存（默认就开着，20 秒一次），忘记按 `Cmd+S` 也不丢；
4. 每天收尾用「版本快照 · 时间机器」留一份，改错了随时回滚。

### 18.3 项目文档 / README

1. 直接编辑仓库里的 `README.md`：代码块高亮、表格、图片、徽章都能所见即所得地写；
2. 截图 `Cmd+V` 落盘到 `imgs/`，写成相对路径（提交进仓库）或图床 URL（不想把大图提交进 git 时）；
3. 发布前 `Cmd/Ctrl + Shift + E` 导出一份自包含 HTML 给非技术同事看，或让浏览器打印成 PDF。

### 18.4 长文写作 / 论文草稿

1. 偏好设置把界面缩放调到 1.2、正文字号 18–20，读起来省力；
2. 打字机模式 `F9` 让当前行始终居中，专注模式 `F8` 压暗其它段落；
3. 结构靠大纲：`Cmd + Ctrl + 1` 打开，点标题在章节之间跳；
4. 引文与注释用脚注 `[^1]`，参考文献列表放文末段落，导出 HTML 时保留编号。

### 18.5 整理旧笔记

1. 「工作区全文搜索」找散落各文件的关键词，回车打开；
2. 进入文档后用 `Cmd/Ctrl + F` 勾选正则批量改写（例如把 `img/` 统一成 `imgs/`，替换框写 `$1` 保留捕获内容）；
3. 替换结果异常立刻 `Cmd/Ctrl + Z` 整体撤销；
4. 文件重命名 / 移动在侧栏文件树里做，双链关系图随后会反映新名字。

### 18.6 边查资料边写（终端）

`Cmd/Ctrl + J` 打开终端：`git status`、`ls`、`rg 关键词`、甚至 `vim`（备用屏与颜色都正常）都能在同一个窗口里跑；点回正文即恢复编辑，`Cmd/Ctrl + J` 收起面板。

## 19. 常见问题

**快捷键按了没反应？**
先看焦点在哪：终端面板有焦点时，除 `Cmd/Ctrl + J` 外所有应用快捷键都会让位给 shell。若确实要点两次才生效，通常是鼠标在按住期间有轻微位移——已经把「点击」判定放宽（10 px / 1.5 s），若仍复现，请记录具体位置。

**中文显示成方块 / 乱码？**
正文优先找阿里巴巴普惠体 3.0；把它放进 `~/.markd/fonts/`（文件名含 `puhuiti`）后重启。终端里中文变 `?` 是 locale 问题，应用已在缺 `LANG` 时补 `en_US.UTF-8`，若你的 shell 自己覆盖了 `LANG`，改回 UTF-8 变体。

**图片显示「图片未找到」？**
路径是相对当前文档所在目录解析的；检查文件是否被移动、或者写的是绝对路径 / 图床 URL。远端 URL 会显示「正在加载图片」，失败时退回占位框，重新滚动进入视口即可重试。

**公式没渲染出来？**
确认偏好设置 → Markdown → 数学公式已开启；行内 `$…$` 要求两侧成对，块级用独立成段的 `$$…$$` 或 ` ```math ` 代码块。

**`$` 被误认成公式（比如写价格）？**
关掉「数学公式」开关，或者用 `\$` 转义。

**导出的 HTML 图片看不到？**
关闭「导出 HTML 时内嵌图片」时导出的是相对路径引用，需要连同图片目录一起分发；单文件分享就把它打开。

**关系图 / 全文搜索一片空白？**
说明还没有工作区（或工作区里没有别的 Markdown 文件）。先用「文件 → 打开工作区…」指到笔记根目录；关系图是打开面板后才在后台扫描的，稍等片刻。

**想彻底回到初始状态？**
删除（或改名）`~/.markd/config.json`，重启即按首次启动处理。想连折叠与快照一起清掉，再删 `folds.json` 与 `snapshots/`。

**大文档变卡了？**
先确认是不是在源码模式（每键整篇重解析）。混合模式下帧成本与文档长度无关；若确实出现持续掉帧，记录文档规模与正在执行的操作，这是需要修的信息。

**多显示器之间窗口字太小？**
用「界面缩放」调，而不是改系统 DPI；缩放范围 0.8–1.6。

**图床上传失败？**
「测试上传」按钮会给出具体错误。常见原因是令牌权限不足、仓库或分支不存在、目录路径模板写了非法字符。

## 20. 已知限制

- **表格没有增删行列的图形化菜单**：结构改动要进源码态改分隔行与竖线。
- **源码模式在大文档上代价高**：冷首帧数秒、每键整篇重解析（约 1 秒 / 键）。混合模式不受影响。
- **PDF 需要借道浏览器打印**，没有内置排版引擎。
- **图床目前只支持 Gitee 仓库**（其它平台需要新增适配）；令牌明文保存在本地配置里。
- **图片 / 公式纹理缓存只增不减**：图片极多的文档长时间翻阅内存会持续上升，重开文档释放。
- **超长引用点进编辑态后，换行点会挪一点点**：渲染态的行宽用满正文宽度，编辑态的输入框给光标留了 8px，所以一段需要软换行的长引用在编辑态可能提前一个字符换行。左侧竖线和文字起点都不动，动的只是断在哪里。
- **不支持协作、批注、插件系统**。
- 内容完全相同的两个代码块会共享同一条折叠记录（折叠状态以源码文本为键）。
- 工作区文件树有 4000 文件 / 6 万条目上限，超限的目录不会显示。
